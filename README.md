# Books

Reading editions published by DROG. One repository, one page per book, one
release per edition.

This repository distributes; it holds no manuscript and no build system. What
is here is what a reader can have:

- **Releases** — each is one frozen edition of one book, tagged
  `edition-<book>-<label>`. PDF, EPUB, IDML, and the audiobook as one MP3 per
  chapter. An edition is built once and never replaced, so a link keeps working
  and page 34 still means page 34.
- **`gh-pages`** — a page per book, each at its own path.

Licences differ per book and each edition states its own. *Disinfonomics: The
Market of Lies* is CC BY-NC-SA 4.0: free to share and adapt non-commercially,
with credit, under the same licence. Print copies are sold through
print-on-demand.

Everything here is generated by the private engine repository when an edition
is cut. Nothing should be edited by hand — the next edition would overwrite it.
