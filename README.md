# Disinfonomics: The Market of Lies

**Bram Alkema** · Saufex Publishing

This repository distributes the book. It holds no manuscript and no build
system — those live elsewhere. What is here is what a reader can have:

- **Releases** carry each frozen edition: PDF, EPUB, IDML, and the audiobook as
  one MP3 per chapter. An edition is built once and never replaced, so a link
  keeps working and page 34 still means page 34.
- **`gh-pages`** serves the book's page.

The book is licensed **CC BY-NC-SA 4.0** — free to share and adapt
non-commercially, with credit, under the same licence. Print copies are sold
through print-on-demand, which is what the buy links on the page are for.

Everything here is generated. Nothing in this repository should be edited by
hand: the next edition would overwrite it.
